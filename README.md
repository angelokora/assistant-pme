# Éléa (assistant-pme)

Prototype interactif d'Éléa, l'assistant IA des dirigeants de PME, par Fasfox. Web, mobile first, adapté à la tablette et à l'ordinateur. Sans backend : un moteur rejoue des scénarios JSON.

**Commencez par `AGENTS.md`.**

```bash
npm install
npm run dev   # prototype
npm run ds    # vitrine du design system
```

| Dossier | Contenu |
| --- | --- |
| `docs/` | Vision, architecture, catalogue des blocs, maquettes Figma, transcript |
| `apps/design-system/` | Tokens, composants, `DESIGN.md`, vitrine |
| `apps/web/` | Le prototype et ses scénarios |
| `tickets/` | Règles de travail et backlog (local, non versionné) |
